# fili icons

Interface icons for fili: 24 px grid, 1.75 px stroke, round caps and joins. Outline `#1B2A41` with one stroke in
`#0E9AA7` (the "thread"). On a dark background use `#E8EEF5` for the outline and `#4FD1DC` for the thread.

| file | where it is used |
|---|---|
| `usb-device.svg` | device list |
| `install.svg` | Install |
| `reinstall.svg` | Reinstall |
| `restore.svg` | Restore |
| `diagnose.svg` | Diagnose |
| `certificates.svg` | Certificates |
| `licenses.svg` | Licenses |
| `save.svg` | Save output |
| `refresh.svg` | Refresh |
| `help.svg` | Help |
| `about.svg` | About |
| `support.svg` | Ko-fi |
| `usb-reset.svg` | usb-reset |
| `hubs.svg` | Show hubs |
| `admin.svg` | Administrator |
| `force.svg` | Force (protected class) |
| `twins.svg` | All matching |
| `filter.svg` | Filter driver |

`app-icon.svg` is the application icon (executables and installer).
