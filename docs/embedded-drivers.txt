Drivers embedded in this wdi-simple.exe, and the license of each
=================================================================

This file is passed to scripts/package_wdi_bundle.py (--drivers-file) and is shipped as
THIRD_PARTY/embedded-drivers.txt. It lists ONLY what the binary really contains: if you build wdi-simple.exe
with fewer drivers (libwdi accepts any of --with-wdkdir, --with-libusb0, --with-libusbk), delete the entries
you left out. Facts below were checked on 2026-10-13 against the files used for the reference build; it is
not legal advice.

fili does not modify any of these files. libwdi copies them into the package it generates at run time.


1. WinUSB: NESSUN file Microsoft ridistribuito (dal 20/10/2026)
   wdi-simple.exe NON incorpora i co-installer del WDK 8.0 (WdfCoInstaller01011.dll, winusbcoinstaller2.dll): la build li
   toglie con scripts/strip_coinstallers.py (embedder_files.h, template INF e CAT di libwdi). Servono solo a Windows XP/Vista;
   da Windows 10 winusb.sys e il framework WDF sono già nel sistema, quindi non c'e' niente di Microsoft da ridistribuire e
   la manleva della licenza WDK non si applica. Verificato su Windows 11 x64: WinUSB, libusbK e libusb-win32 si installano
   e si ripristinano (scripts/driver_matrix.py). Chi vuole comunque i co-installer (Windows < 10) ricompila con
   WITH_COINSTALLERS=1 e si assume le condizioni Microsoft (docs/licenza.md).
