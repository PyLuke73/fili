Drivers embedded in this wdi-simple.exe, and the license of each
=================================================================

This file is passed to scripts/package_wdi_bundle.py (--drivers-file) and is shipped as
THIRD_PARTY/embedded-drivers.txt. It lists ONLY what the binary really contains: if you build wdi-simple.exe
with fewer drivers (libwdi accepts any of --with-wdkdir, --with-libusb0, --with-libusbk), delete the entries
you left out. Facts below were checked on 2026-10-13 against the files used for the reference build; it is
not legal advice.

usbdrv does not modify any of these files. libwdi copies them into the package it generates at run time.
