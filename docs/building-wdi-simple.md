# Building wdi-simple.exe

`usbdrv install/reinstall` runs **wdi-simple.exe** from [libwdi](https://github.com/pbatard/libwdi) (LGPL-3.0-or-later).
It is not shipped here: you build it (or provide your own) and tell usbdrv where it is: `--wdi PATH`, `[tool] wdi_path`
in `usbdrv.toml`, `%USBDRV_WDI%`, a copy on `PATH`, or `build\wdi-simple.exe`.

## What libwdi needs

`configure` refuses to run unless you give it a source of driver files: one of `--with-wdkdir=DIR` (WinUSB from a WDK;
expects `DIR/redist/wdf/<arch>/WdfCoInstaller01011.dll` and `DIR/redist/winusb/<arch>/winusbcoinstaller2.dll`),
`--with-libusb0=DIR`, `--with-libusbk=DIR`, or `--with-userdir=DIR` (your own driver). Add `--enable-examples-build`
to build `wdi-simple.exe`. Decide what you embed and check each license first (`licenza.md`, `NOTICE`).

**Option A — MSYS2 / MinGW-w64 (UCRT64 shell)**
```bash
pacman -S --needed git make autoconf automake libtool mingw-w64-ucrt-x86_64-gcc
WDK_DIR='C:/path/to/WDK' scripts/build_wdi_simple.sh   # clones libwdi v1.5.1 into third_party/, builds, copies to build/
```
**Option B — Visual Studio:** open `third_party/libwdi/libwdi.sln` (see libwdi's wiki, "Install") and build `wdi-simple`.

## How usbdrv calls it (from `examples/wdi-simple.c`)

`wdi-simple -n NAME -f usbdrv.inf -v 0xVID -p 0xPID [-i MI] -t TYPE -d DIR [-w] [--filter] [-s] [-o MS] -l LEVEL`
where `TYPE` is 0 WinUSB, 1 libusb-win32, 2 libusbK, 3 usbser. It extracts the package into `DIR`, **self-signs the catalog,
adds the certificate to the Root and TrustedPublisher stores** (`SelfSignFile` in libwdi's `pki.c`) and installs the driver.
`-x` (extract only) performs the same signing, so usbdrv does not use it: `usbdrv extract` writes an unsigned INF itself.
Certificates are named `CN=<hardware id> (libwdi autogenerated)`; `usbdrv cert-remove` finds them by that suffix.
